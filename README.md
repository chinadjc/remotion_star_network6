# Star Network — Remotion SVG particle film

- 1920×1080, 30 fps, 60 seconds (1800 frames)
- Animated SVG points and proximity-based connections
- Central amber star, pulsing light, slow particle drift
- Chinese closing title

## Run
```bash
npm install
npm run start
npm run render
```
Rendered file: `out/star-network.mp4`
